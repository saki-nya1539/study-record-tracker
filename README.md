# 学習記録トラッカー

毎日の勉強を記録して、成長を可視化するWebアプリです。

## デモ

👉 [アプリを開く](https://saki-nya1539.github.io/study-record-tracker/)

## 機能

- 学習内容・教科・時間・メモを記録できる
- 総学習回数・総学習時間・平均時間・今日の回数を表示
- 教科でフィルター、キーワードで検索
- 記録の編集・削除
- データはブラウザに自動保存（localStorageを使用）

## 使用技術

- HTML / CSS / JavaScript（純粋なフロントエンドのみ）
- localStorage（データ保存）

## 使い方

1. 学習内容・教科・時間を入力
2. 「記録する」ボタンを押す
3. 記録が一覧に追加される
4. ブラウザを閉じてもデータは消えない
